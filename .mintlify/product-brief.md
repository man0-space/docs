# Product brief

## Description
Man0 lets people build workflows from model, connector and specialist-agent steps, run them with text or media, and publish workflows for others to use.

## Audience
App readers want to build and run useful workflows. Technical readers need precise graph, runtime, NEAR account, contract, payment and API structures.

## Tasks
Build with Vibe or Canvas, choose catalog resources, test, save, run, connect accounts, publish, fund a spending session and inspect results and earnings.

## Presentation
App instructions use the actual UI and second person. Technical sections explain source-grounded behavior with short examples. Use real screenshots. Keep defects and research observations outside published documentation.
