# Documentation instructions

Use the app and backend source to verify product behavior before writing. Public documentation describes Man0; keep research notes and source defects outside this directory.

- Write short, useful sentences in active voice. Use second person for app walkthroughs.
- Match the app's exact UI labels and bold them. Use sentence-case headings.
- Keep code examples small, with language tags and valid request structures.
- Link internal pages with root-relative paths without extensions.
- Use actual app screenshots at their original resolution, with descriptive alt text.
- Use Man0 assets and design tokens. Never copy another product's content.
- Keep endpoint structures in openapi.json, rather than duplicating parameter tables.
- Validate pages, navigation, links and assets locally. Never deploy or trigger deployment.
