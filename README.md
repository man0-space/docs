# Man0 documentation

Mintlify documentation for the Man0 app, workflows, NEAR integration and API.

App: https://app.man0.space  
API: https://api.man0.space  
Source organization: https://github.com/man0-space

[Project overview](https://github.com/man0-space/submission) · [Documentation site](https://docs.man0.space)

Run `npx mint@latest dev --no-open` in this directory for a local preview. Check changes with `npx mint@latest validate` and `npx mint@latest broken-links`.

Endpoint pages read their request and response structures from `openapi.json`. Keep the specification matched to the backend route registrations and input schemas.
