The Man0 API exposes the app’s workflow graph, Vibe builder, saved conversations, creator analytics and NEAR account operations.

Base URL: **`https://api.man0.space`**. Routes use `/api`; ordinary requests return JSON. Vibe and workflow execution use newline-delimited JSON streams.

## Read the public catalog

```js
const api = 'https://api.man0.space/api';
const models = await fetch(`${api}/catalog/models`).then(r => r.json());
const workflows = await fetch(`${api}/market`).then(r => r.json());
```

The first response is an array of resource entries. Market returns published workflow listings with their graph, terms and creator data. Use returned IDs for selection and follow-up requests.
