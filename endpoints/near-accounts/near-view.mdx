---
title: "Read a NEAR method"
description: "Read a method on an allowed Man0 NEAR contract with JSON arguments."
keywords: ["Man0", "API", "NEAR accounts"]
openapi: "openapi.json POST /api/near/view"
---

Allowed targets include the configured Factory, Workflow, Reputation and Validation contracts, `intents.near`, USDC contracts and the active network’s discovered Intents verifier/token contracts. The API resolves the target network from that contract.
