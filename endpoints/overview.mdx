Base URL: **`https://api.man0.space`**.

Public reads include configuration, categories, catalogs, published workflows and creator profiles. Account operations use the Man0 bearer token; workflow execution uses a Compose spending session or x402 authorization.

Ordinary responses are JSON. Vibe, run and watch endpoints stream `application/x-ndjson`; read the [streaming guide](/developer/streaming) before implementing their event handling.

Workflow writes use their `modified` timestamp in `If-Match`. The API returns errors as `{ error, code? }`, with thread/requirement fields where needed. Requests have a rate limit of **120 per minute**.

The [OpenAPI specification](/openapi.json) contains shared request/response structures and registered OAuth aliases. The [developer guides](/developer/overview) explain how to combine these operations.
